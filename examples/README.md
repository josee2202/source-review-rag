# Synthetic files

These three fictitious documents come from the thesis project this repository was adapted from.
They are banking-themed because of that origin. The automated tests use them to exercise real PDF
(with real page numbers) and DOCX reading, and you can use them to try the app with files.

They are not a demo corpus or a benchmark, and they say nothing about the quality of the results.

| File | Format |
|---|---|
| `synthetic/normativa_sintetica_pd.pdf` | PDF, two pages |
| `synthetic/metodologia_banco_ficticio.docx` | DOCX |
| `synthetic/tecnico_banco_ficticio.docx` | DOCX |
